# Portfolio

## Descrizione

Questo portfolio presenta i miei progetti, competenze e informazioni di contatto in un'interfaccia moderna e responsive.

## Tecnologie Utilizzate

- React
- Vite
- Tailwind CSS
- JavaScript/TypeScript

## Caratteristiche

- Design responsive e moderno
- Navigazione fluida tra le sezioni
- Presentazione progetti
- Sezione competenze tecniche
- Form di contatto
- Ottimizzato per le performance

## Installazione e Sviluppo Locale

Clona il repository:

```bash
git clone https://github.com/purplepi3/purp7epi3.github.io.git
cd purp7epi3.github.io
```

Installa le dipendenze:

```bash
npm install
```

Avvia il server di sviluppo:

```bash
npm run dev
```

Il sito sarà disponibile su `http://localhost:8080`

## Build per Produzione

```bash
npm run build
```

I file ottimizzati saranno generati nella cartella `dist/`

## Deploy

Il sito è automaticamente deployato su GitHub Pages ad ogni push sul branch main.
